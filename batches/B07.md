# B07 — Integration assist (checklist spec)

- **Owner (batch map):** Rowan — agent-agnostic: whoever claims it executes it cold.
- **Crate:** none of its own. Integration runs across `queue-core`, `queue-store`,
  `guardrail`, `agent-runtime`, `assess-server`, `stack` — and at wave closes, the whole workspace.
- **Claim:** topology A = bus post in room 1 naming B07 (+ the wave); topology B = branch `batch/B07`.

## Job

B07 is the seam work between batches. It owns no source files. Run this checklist
at every wave close (see `docs/RUST_REBUILD_PLAN.md` §4) and whenever two PORTED
batches first meet:

1. `cargo build` for the full workspace; fix seam errors (types, trait bounds,
   duplicated definitions) in the crate that owns the contract — never by
   copy-pasting a type into the consuming crate.
2. Contract seam check, byte-for-byte against the frozen contracts:
   job kind `trio-assessment` v1; deterministic job id
   `trio-<sha256(product + "\0" + timestamp + "\0" + frame bytes)[:32]>`;
   result key `trio:{jid}:result`; result body
   `{job_id, status, assessment, error, model, latency_ms, completed_at}`;
   `/api/assess` v2 shape; queue claim = SET NX lease + heartbeat, result
   written once; guardrail counts every Spark call against the $75 cap.
3. Cross-crate test pass: `cargo test` for the full workspace; triage failures
   to the owning batch and route the fix there — B07 does not rewrite another
   batch's port, it files the seam and helps land the fix.
4. Compile-error triage for the wave: collect gate errors, group by error
   class, apply the stall rule (same class three rounds = park, write the
   blocker into the batch spec, move on).
5. Fallback integrity: confirm no Python/Node original was edited or deleted
   by any batch in the wave (`git diff` against the wave's start tip).

## Done criteria

- The wave's PORTED batches build and test together as one workspace.
- Seam fixes committed as `B07: <seam> — UNCOMPILED` / `B07: <seam> PORTED`
  under the same two-gate rule as every batch.
- Completion report (one line):
  `B07 <PORTED|BLOCKED> wave=<n> workspace-build=<pass/fail> workspace-test=<passed>/<total> commit=<sha>`

## Known traps

- A seam fix that changes a frozen contract is wrong even if everything compiles.
- Never merge a branch whose batch is not PORTED at both gates (topology B)
  or whose bus claim is still open (topology A).
