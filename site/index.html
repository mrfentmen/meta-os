Meta OS

A platform that never sleeps.

Meta OS is a real operating system with its own kernel, built for agents and for users. Systems plug into the platform and run on top of it.

Kernel K1 boot proven in QEMU K2 to K6 merged to main, boot logs on record Merged tree Mac compile is the next proof Deadline Meta AI Hackathon, Nov 4, 9:00 PM ET

The platform

Seven layers, bottom to top. The kernel is Rust. Services are written in Goose. The agent runtime and the shell are written in Lobster. Every layer is real code in one public repository.

The systems

Meta OS is the platform. These are the systems that run on it.

System one

Imperium

The three services that answer 911, built to watch camera feeds with Muse Spark. The runs on record use simulated feeds, not live cameras. Vigiles for police awareness, Ignis for fire, Medicus for EMS scene awareness only: visible signs, never diagnosis. Small signs are recorded and shown. Big signs run the full chain. Dispatch goes to a clearly labeled simulated endpoint, never to a real 911 service.

System two

Science Lab

A working laboratory on the platform. Project LABORATORY's first build is merged and passed its dress rehearsal, reproducing a published result on held-out data; its first real discovery cycles (001-004) have run and are recorded in the repo. Hortus sits inside it as the breeding engine that grows and selects new candidates. Heatsinks are its current practice test, not its limit.

Candidate system

Musica

Music generation and catalog tooling, built as a product line of its own and being packaged to plug into the platform as a system.

Retired

Custos

Retired as a standalone system (2026-11-02). The night watch idea — a guard for machines, checking what should stay quiet through the night — now lives in the OS's agents.

Adopted

Officina

The invention workshop. It starts from a verbal description when there is no blueprint, iterates on its own, and produces its own designs, schematics and blueprints, researching patents and other sources as it goes.

On main

The Board

The messaging board: the crew relay, remade as a board service that runs beside the OS today (host service + web viewer). Wiring it into the OS shell is next.

What is proven today

The adopted claim (PAX_12H.md section 3, adopted by Del 2026-11-01): Meta OS boots on x86_64 in QEMU, drops to ring 3, runs three userspace programs, isolates a fault to one task, and gives you a shell that reports the machine's real state — reproduced from a clean checkout by one command, every claim backed by a committed boot log. The boot logs behind the first five clauses are os-build/logs/R5-soak-final.txt and os-build/logs/K6-boot.txt; the gate record is 7/7 in OPENCODE_ROUND5_REPORT.md.
