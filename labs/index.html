WHAT EACH MODE OWNS

QuestionMolecule bench owns itCycle report owns it
What does this molecule look like?Yes — 3D structure, element filter, atom/bond countsNo
Where did a structure come from?Yes — PubChem CID provenance per compoundNo
Did a computation reproduce?NoYes — verdict (MATCH/DIFFER) per cycle
How strong is a claim?NoYes — recorded ladder level, never upgraded
Can I audit it?Structures validate client-sideYes — every claim links its source files

Neither mode invents data: the bench renders only validated embedded JSON (or a live PubChem fetch the user asks for), and the cycle report renders only recorded ledger/score values. Offline, both keep working from the embedded copies.
