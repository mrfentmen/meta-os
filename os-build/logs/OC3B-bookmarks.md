# OC3B-012/013 — bookmark defaults (Meta pages only)

Shipped bookmarks: none. The start page (OC3B-startpage.html) is the
launch surface and carries four on-machine entries; no bookmark file
is seeded, so there is nothing to audit into compliance.

OC3B-013 audit: vacuous pass — zero bookmark URLs shipped, therefore
zero Ubuntu/Apple links. If the ISO lane seeds bookmarks later, this
file gets a real audit row at that time; until then the honest record
is "none shipped".

Rationale (OC3B-010 applies): a seeded bookmark to any remote page is
a phone-home on first click. Local-first means no seeded remotes.
