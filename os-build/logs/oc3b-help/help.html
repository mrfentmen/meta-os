MetaOS Help

On this machine. No network needed for anything below.

First boot: five things

  1. Open Files — your Home folder is the start of everything.
  2. Open Terminal — the welcome ribbon draws once, then stays out of your way.
  3. Open Settings — wallpaper, display, and Wi-Fi live here.
  4. Open Web — the start page works offline.
  5. Open Demo Tour from the menu for the sixty-second walkthrough.

Keyboard shortcuts (Xfce defaults)

  • Super + T — terminal   Super + F — files
  • Alt + F2 — run a command   Alt + Tab — switch windows
  • Ctrl + Alt + Del — log out dialog   Print — screenshot tool

Defaults as shipped; confirmed on first boot. If a binding was remapped, the Settings > Keyboard page shows the truth.

Troubleshooting, top issues

  1. No Wi-Fi networks listed. Open Settings, check the panel; real fix needs the hardware in front of you — untried here, owner OC1.
  2. Wrong resolution. Settings > Display lists the modes the cable reports. Untried here, owner OC1.
  3. Forgot the user password. No backdoor exists on purpose. Reinstall is the documented path.
  4. An app will not open. Every launcher has a TryExec guard, so a missing program hides its icon instead of erroring. Report which one.
  5. Sound is silent. Open Volume Control; unmute Master. Untried here, owner OC1.
  6. Browser asks to sign in. Dismiss it — MetaOS has no accounts. If it persists, file it as a defect.

Rule used throughout: a fix is listed as tried only with a boot log behind it; everything else is named with its owner.

Privacy: what this system does with your data

Nothing leaves the machine. No accounts, no sync, no telemetry, no bundled search engine phoning home. The browser opens a local start page; the file manager never networks unless you open a network location yourself. This statement matches the shipped configuration — local-only by construction, verified in the per-app quiet notes, with packet-capture confirmation explicitly left as an OC1 boot task.

Where things live

  • Apps: /usr/share/applications · Your files: /home/<you>/
  • Start page + demo: /usr/share/metaos/start/index.html, /usr/share/metaos/demo/tour.html
  • Welcome flag: ~/.config/metaos/welcome-shown · Settings: Xfce configs under ~/.config/

Image paths as installed by the ISO lane; existence confirmed at first boot.
