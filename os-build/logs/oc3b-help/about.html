About MetaOS 1.0

A Xubuntu-based Xfce desktop, Meta-branded, built to demo on.

SystemMetaOS 1.0 — Xubuntu 24.04 "Noble" base, Xfce desktop
KernelLinux amd64 (Debian-image route: linux-image-amd64). The bare-metal Rust kernel is the 2.0 track, not this image.
BaseXubuntu core remaster (Cubic route); Debian live-build route carries the same package set
Track split1.0 = this remaster, demonstrable now. 2.0 = bare-metal Rust kernel + Goose services + Lobster agent runtime (K1–K6 build steps; not booted here)

Kernel/base strings describe the build inputs on record. Running-kernel proof comes from OC1's boot serials, not from this page.
