# OC3B-017 — browser operator doc

Open Web from the menu or dock. The start page lists what this
machine can do. Address bar works for file:/// paths and, when the
machine is online, ordinary URLs. Nothing here signs you in and there
is no account to sign into. If a consent screen ever appears, it is a
Chromium version artifact, not MetaOS policy — screenshot it and file
it under OC3B-browser-defects.md. To reset the browser to ship state,
delete Chromium's profile dir and relaunch from the same icon.
