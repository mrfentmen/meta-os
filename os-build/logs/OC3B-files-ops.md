# OC3B-039 — file manager operator doc

Open Files from the menu or dock. Home on the left, folders in the
middle. Double-click opens; right-click does everything else
(create folder, rename, compress, properties). Show hidden files from
View, or press Ctrl+H. Eject USB sticks from the sidebar arrow before
unplugging. If a location asks for a password you do not have, stop
and ask — do not type it anywhere except the users settings screen.
