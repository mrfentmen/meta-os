# Autostart audit — `metaos-contracts/AUTOSTART.md`

Rule: every autostart entry must name `TryExec=` pointing at its own binary, so a
missing program is skipped instead of showing a broken entry at login.

Generated by scanning every `.desktop` file on this branch. 1 autostart entry found.

| File | Exec | TryExec | Verdict | Note |
|---|---|---|---|---|
| `iso/base/autostart/meta-first-login.desktop` | `/usr/local/bin/meta-first-login` | `/usr/local/bin/meta-first-login` | **PASS** | skipped cleanly when the binary is absent |

## What this does not cover

The rule also governs the agent-layer entries that OpenCode 2 ships as
`/etc/xdg/autostart/metaos-*.desktop`. Those live on another branch and are
not present here, so they cannot be audited from this tree. When they land,
the same scan covers them: it walks every `.desktop` file, not a fixed list.
