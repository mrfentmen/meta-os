pty bridge test contract (honest scaffolding: browsers cannot do raw TCP) No WebSocket here on purpose — ptyd.py speaks raw TCP, which the browser cannot open. A real terminal window needs a helper (e.g. websockify or a native client). This page only records the contract. 
host:     127.0.0.1
port:     18933
framing:  none (raw bytes both ways; server pumps pty master <-> socket)
session:  one client at a time; while busy new conns get "\r\n[busy]\r\n" then close
shell:    fresh /bin/bash -i per connection on an 80x24 pty
limit:    fixed 80x24, no resize protocol (winsize set via TIOCSWINSZ after fork)
cleanup:  server SIGKILLs + reaps child on client disconnect, ready for next
