## What this index cannot tell you

- When a log was produced. The filename and the git commit are the only timestamps; a file's
  mtime is checkout time, not boot time.
- Whether the run that wrote it was on the same commit as the tree you are reading.
- Whether a boot the log does not mention was attempted. A missing log is not a failed boot.
