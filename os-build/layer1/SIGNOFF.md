## What Layer 4 is

The system services of Meta OS: 25 services with code and native tests, plus 18 shared libraries,
written in Goose, sitting above the kernel and below the agent runtime and shell. It owns the boot
record, the clock, logging and rotation, the supervisor and its boot order, the permission table,
storage, the filesystem, the network stack and protocol pack, sockets' neighbour services, updates,
the audit trail, the agent host, the session, the display, input, devices and the watchdog.

115 Goose files, 24,785 lines. 165.4 KiB of static storage across 33 units. No heap, no threads,
no libc. Four directories (`sockets`, `registry`, `devmgr`, `build`) are placeholders with no code
and are counted separately in `SERVICES_SCOPE.md` rather than padded into the service count.

**RUNS is not BOOTS.** Every run above is a host process linked against `host/host_shim.c`, which
implements the ten `sys_*` symbols and **refuses five on purpose** — spawn, kill, net send, net recv,
read_key. A green suite therefore proves service logic and proves nothing about the kernel.

## What is not proven

| Gap | Why it cannot be closed here |
|---|---|
| **Anything boots a service** | no `sys_spawn`/`sys_kill` exists; the supervisor decides and records, and nothing executes the decision |
| **The supervisor starts, stops or restarts a process** | it has no actor: `t52_supervisor` drives the state machine, not a PID |
| **Persistence** | storage is RAM by design; the remount test proves one process, not a reboot |
| **The network reaches a wire** | the protocol pack talks to itself through `tests/harness/link.goose`; there is no NIC |
| **A Lobster program calls a service** | zero `.lobster` files in the repo; the callable surface is one no-argument `svc_entry` per service (`LOBSTER_BINDING.md`) |
| **Log segments exist as files** | rotation names them correctly and nothing writes them to MOSFS01 yet |
| **Boot time, services started at boot, runtime memory** | kernel numbers, and this checkout has no boot log; `BOOT_PLAN.md` is a plan |
| **A service that hangs mid-start is detected** | the start timeout is still unbuilt (`FAILURE_TRACE.md` item 4) |
