## BF5-06 — The face layer's quiet failures: a table that fills, an import that applies nothing, a clock that goes backwards

`tests/t94_face_failures`

## The refusal that makes these transcripts evidence

`os-build/layer1/host/host_shim.c` implements the ten `sys_*` externs and
**refuses five on purpose**: `sys_spawn`, `sys_kill`, `sys_net_send`,
`sys_net_recv` return a failure code, and `sys_read_key` reports "nothing
pending". A shim that faked those would make every transcript above green for a
reason that does not exist on the kernel. The refusal is the honest part.

## Reproduce, on this machine

```
./os-build/layer1/run_native.sh            # every program, with pass/fail per test
./os-build/layer1/check_services.sh        # typecheck every root and every test
```

Neither command boots anything. There is no kernel in this loop: the run is a host
process with a substituted syscall surface, and that is the whole claim.
