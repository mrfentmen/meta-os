## What this does not clear

- **Git history is not scanned here.** A key removed from the working tree is still in the
  history; that is the OPSEC pass, and it is a separate run with a separate report.
- **Only 2,248 text files were read** (404 non-text, 0 binary, 7 oversized, 5 cache dirs
  skipped). A secret in an unread file is not cleared by this report.
- **`assigned-secret` can miss things.** A credential assigned without quotes, built by
  concatenation, or read from the environment leaves no pattern to match. This is a count of
  what the patterns found, not a proof of absence.
