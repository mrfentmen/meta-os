## What this cannot tell you

- A pattern is not a live credential. `assigned-secret` matches can be placeholders, and every
  one of them needs a human look at the line. `confirmed` means the shape is unambiguous, not
  that the secret is real or still valid.
- It does not look at git history. A secret removed from the working tree is still in the
  history, and that check is a separate pass (OPSEC).
- It does not validate anything against a provider, because that would mean sending the value
  somewhere, which is the one thing this module will not do.
