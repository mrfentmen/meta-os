# R13-039 — heartbeat under clock moved backwards

Status: **GAP FILED — no clock read**.

## Requested condition

The task asks for a failure-path test of `services/heartbeat` under “clock moved backwards”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`services/heartbeat/heartbeat.goose:8-19` uses `sleep(1.0)` and appends the token `beat`. There is no clock read, no timestamp and no elapsed-time arithmetic. `grep -nEi 'clock|time|now|timestamp|backward'` matches only the header comment about a timestamped line.

## Observed behaviour

The daemon cannot notice a backwards clock because it never reads one. It sleeps one second per iteration and stops after 3,600 iterations or a `STOP` file; wall-clock discontinuities do not affect it.

## Gap

The condition is inapplicable to the code. If timestamps are intended (the header says they are), the clock dependency and its monotonicity rule must be added first.

## Owner

heartbeat clock contract; time service.
