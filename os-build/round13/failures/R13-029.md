# R13-029 — console under state file corrupt

Status: **GAP FILED — no state file**.

## Requested condition

The task asks for a failure-path test of `services/console` under “state file corrupt”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nEi 'state file|state_file|save|load|persist|open\(|read_file|write_file' services/console/*.goose` matches only cursor save/restore escape names (`SEQ_SAVE_CURSOR`), not persistence. `console.goose:46` initialises an in-memory `MsgRing`; there is no path.

## Observed behaviour

Console state is process memory: edit buffer, history ring, cursor and escape state. Nothing is written to a file, so a corrupt state file cannot be opened. A fresh process gets empty state by construction.

## Gap

The condition is inapplicable. If console state is to survive a restart, the save/load path does not exist yet; the restart task is Section C.

## Owner

console persistence; Section C restart work.
