# R13-048 — session under peer sends garbage

Status: **GAP FILED — no peer transport**.

## Requested condition

The task asks for a failure-path test of `services/session` under “peer sends garbage”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nEi 'socket|peer|connect|send|recv|garbage' services/session/*.goose` returns no matches. `login_key` rejects control bytes with `E_INVAL` at `login.goose:131`; `ses_*` functions take ids and booleans, not bytes from a peer.

## Observed behaviour

There is no socket or peer. The closest real refusal is a control byte typed into `login_key`, which returns `E_INVAL` without entering a field. That is a keyboard input rule, not a peer-garbage parser.

## Gap

A peer-garbage test needs the IPC transport that session does not own. Do not relabel the login control-byte refusal as network input validation.

## Owner

session transport; socket service.
