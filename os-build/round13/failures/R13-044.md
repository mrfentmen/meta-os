# R13-044 — net under log target unwritable

Status: **GAP FILED — no log target**.

## Requested condition

The task asks for a failure-path test of `services/net` under “log target unwritable”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nEi 'log|target|write|serial|file' services/net/*.goose` returns `target_mac`/`target_ip` fields and comments about not logging idle links. There is no log sink, file path or serial write in the net modules.

## Observed behaviour

The packet interface counts drops (`dropped`) and returns codes; it does not log. An unwritable log target cannot fail a send or receive because no send or receive writes a log.

## Gap

A log-target failure test belongs to the logging layer, not net. The drop counter is the only observability here.

## Owner

net observability; logd integration.
