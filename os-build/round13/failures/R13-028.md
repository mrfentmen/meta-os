# R13-028 — callmatrix under dependency down

Status: **GAP FILED — no dependency edge**.

## Requested condition

The task asks for a failure-path test of `services/callmatrix` under “dependency down”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nE '^import |socket|peer|connect|dependency|dep_' services/callmatrix/*.goose` returns only `import common.err.err;` at line 30 and a comment about sockets in another layer. The matrix is a static bit table; `cm_check` answers policy, not reachability.

## Observed behaviour

`cm_init`/`cm_check` have no dependency handle and no service call. A denied edge (`E_DENIED`) is a policy result; an invalid id (`E_INVAL`) is a caller bug. Neither is a dependency that can be down, and no error envelope from a callee exists.

## Gap

The failure input is absent. A real dependency-down test needs a caller that resolves a service through the supervisor, which is outside this unit.

## Owner

callmatrix/supervisor integration; B-L1-22.
