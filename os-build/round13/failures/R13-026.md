# R13-026 — bootlog under missing config

Status: **GAP FILED — no config input**.

## Requested condition

The task asks for a failure-path test of `services/bootlog` under “missing config”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nEi 'config|cfg|env|missing|E_NOTFOUND' services/bootlog/*.goose` returns one comment line and no configuration call. `bootlog.goose:48-66` formats and writes a record from its arguments; there is no config read, no file path and no startup refusal.

## Observed behaviour

`record(buf, cap, level, msg)` and `stage(level, msg)` have no configuration parameter. There is no state in which a config is missing: the service is a library called with a buffer and a message. A caller that supplies no config still gets a record.

## Gap

The requested condition cannot occur. `services/build/CONTRACT_R13.md` and `services/bootlog/CONTRACT_R13.md` already record the missing startup/config contract; this is the same gap viewed from the failure side.

## Owner

bootlog startup/config contract; Q-B-L1-4.
