# R13-036 — dock under dependency returns an error envelope

Status: **GAP FILED — no dependency call**.

## Requested condition

The task asks for a failure-path test of `services/dock` under “dependency returns an error envelope”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nE '^import ' services/dock/*.goose` returns only `import common.err.err;` at line 27. `dk_launch` records intent and returns a code; it does not call the supervisor or any service.

## Observed behaviour

The dock has no dependency handle and no result-envelope from a callee. `dk_result(id, ok)` takes a boolean from the supervisor; a `false` increments `failures` and clears pending. That is a launch outcome, not a structured error envelope from a dependency.

## Gap

A dependency-error test needs the supervisor/integration path that does not exist in this unit. The existing boolean outcome is the closest real seam.

## Owner

dock/supervisor integration; B-L1-21.
