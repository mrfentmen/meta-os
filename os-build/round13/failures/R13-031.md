# R13-031 — devices under port already in use

Status: **GAP FILED — no claim/open operation**.

## Requested condition

The task asks for a failure-path test of `services/devices` under “port already in use”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`services/devices/README.md` says the table probes `BootInfo.serial.port` (`COM1 0x3F8`) and records `DS_READY`/`DS_ABSENT`. `devices.goose:130-131` calls `dev_add(DEV_SERIAL, "serial", boot.serial.port ...)`; there is no open, claim or busy state.

## Observed behaviour

`dev_add` copies a port number from BootInfo into the table. No code opens the UART or asks whether another owner holds it, so there is no `E_BUSY`/in-use result. The table reports device state, not ownership.

## Gap

Port exclusivity is not modeled. A real in-use test needs the Layer 3 driver open path, which does not exist in this unit.

## Owner

devices/device manager; B-L1-113.
