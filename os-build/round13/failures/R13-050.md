# R13-050 — shell under restart loop (3 fast deaths)

Status: **GAP FILED — no restart policy**.

## Requested condition

The task asks for a failure-path test of `services/shell` under “restart loop (3 fast deaths)”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nEi 'restart|policy|max_restarts|backoff|ST_RESTARTING' services/shell/*.goose` matches only the `ps` output reading `sup_slot_restarts(i)` at `shell.goose:174-175`. Restart policy lives in `supervisor.goose` (`RP_*`, `max_restarts`), not in the shell.

## Observed behaviour

The shell has `sh_run` and builtins, but no supervisor state and no death counter. It cannot restart itself; a restart loop is the supervisor's decision. There is no shell entry that a supervisor restarts in this tree.

## Gap

The requested failure belongs to the supervisor and needs a supervised shell entry; both are missing. Testing `sh_run` three times would not be a restart loop.

## Owner

shell lifecycle; supervisor restart policy B-L1-21.
