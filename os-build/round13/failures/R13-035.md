# R13-035 — dns under unknown command

Status: **GAP FILED — no command interface**.

## Requested condition

The task asks for a failure-path test of `services/dns` under “unknown command”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nEi 'command|cmd|verb|argv|unknown' services/dns/*.goose` returns no matches. The public functions are `dns_build_a_query`, `dns_read_name`, `dns_parse_a`, `dns_query_init`, `dns_query_expired`, `dns_query_sent`, `dns_query_feed`.

## Observed behaviour

There is no command parser and no verb dispatch. Malformed packets are refused by `dns_parse_a` with `E_CORRUPT`/`E_STATE`/`E_RESOLVE`, but that is a wire parser, not an unknown command.

## Gap

The requested input cannot reach this unit. A command interface, if wanted, belongs above the resolver.

## Owner

dns surface; Layer 5 command host.
