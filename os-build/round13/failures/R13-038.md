# R13-038 — fs under killed mid-write

Status: **GAP FILED — no fault injection**.

## Requested condition

The task asks for a failure-path test of `services/fs` under “killed mid-write”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`services/fs/DESIGN.md:138-159` states there is no journal and no write-ahead log; a crash mid-create/mid-unlink/lost-block is described but `the crash story is currently theoretical` because the backend is a volatile RAM disk. Source has no kill/fault-injection call.

## Observed behaviour

No test can kill a host process mid-`fs_write` and then remount the same durable image, because the image is volatile. The documented recovery outcomes (`ORPHAN`, lost block, freed-inode entry) are design claims, not measured results.

## Gap

A kill-at-a-boundary harness and a durable backend are missing. Until both exist, the crash story must stay labeled theoretical.

## Owner

fs crash consistency; B-L1-74 durable block driver.
