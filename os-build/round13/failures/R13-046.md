# R13-046 — notify under manifest entry stale

Status: **GAP FILED — no manifest**.

## Requested condition

The task asks for a failure-path test of `services/notify` under “manifest entry stale”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`grep -nEi 'manifest|entry|stale|version' services/notify/*.goose` matches `Note`/`Entry`-like comments and the dismissal ring only. `notify.goose` has no manifest, version or entry descriptor; the feed is in-memory.

## Observed behaviour

`nt_post`, `nt_dismiss` and `nt_fetch` operate on 12 fixed slots and a dismissal ring. There is no manifest record to be stale, so no stale-entry refusal exists.

## Gap

The condition is inapplicable. A manifest belongs to the service registry, not the notification feed.

## Owner

notify manifest; service registry.
