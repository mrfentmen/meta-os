# R13-041 — logd under start while stopping

Status: **GAP FILED — no lifecycle state**.

## Requested condition

The task asks for a failure-path test of `services/logd` under “start while stopping”, with the
recorded behaviour (refusal, error envelope, or crash) and a test exit code.

## Evidence

`services/logd/entry.goose:10-39` exports `service_main`, initialises, loops, flushes and prints `sink stopping` before returning. There is no start/stop state variable and no second entry point; `grep -nEi 'stopping|start|state|lifecycle'` matches only comments and that print.

## Observed behaviour

Calling `service_main` twice would reinitialise the ring and run a second loop; there is no `E_BUSY`/`E_STATE` for a start during shutdown. The shutdown path is a linear flush and return, not a state machine.

## Gap

Lifecycle exclusivity is unimplemented. A real start-while-stopping test needs the supervisor spawn contract (Q-B-L1-4).

## Owner

logd entry lifecycle; supervisor spawn contract.
