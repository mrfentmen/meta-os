# R13-056 — dns restart / state survival

Status: **GAP FILED — in-memory query only**.

## Requested condition

Kill `services/dns` mid-work, restart it, and record exactly what state survived, what
was lost, and what it re-did. Proof requires before/after state hashes plus a restart log.

## Evidence

`services/dns/dns.goose:296-346` keeps query state in a `Query` value (`Q_*`, `timeout_ms`, `sent_at`). There is no cache, file or save/load; the README calls the resolver “pure: bytes in, bytes out”.

## State ledger

| Question | Answer |
|---|---|
| Survived | Nothing. The query is caller-owned memory. |
| Lost | Transaction id, query state, send time and the parsed answer. |
| Re-did | A restarted caller must build and send a new query; an in-flight DNS transaction cannot be resumed. |

## Gap

There is no DNS process or persisted query. A restart test would test the caller, not the resolver.

## Owner

dns transaction lifetime; socket layer.
