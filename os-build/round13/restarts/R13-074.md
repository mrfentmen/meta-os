# R13-074 — restart test: services/storage

**State: GAP.**

## What the task asks

Kill `services/storage` mid-work, restart it, and record exactly what state
survived, what was lost, and what it re-did. Proof: before/after state hashes
plus a committed restart log.

## What exists

`services/storage` holds 2 file(s), all Goose source and Markdown. There is no binary, no
entry point that runs, and no state file.

Nothing starts this unit, so there is nothing to kill. With no process there is
no state to hash before the kill and no state to hash after the restart, and a
restart log would have to describe an event that never happened.

## Gap

- no state file to hash
- no restart log

Filed as a gap. It is not a failed test: the unit under test is source text.
