# R13-054 — dhcp restart / state survival

Status: **GAP FILED — in-memory client only**.

## Requested condition

Kill `services/dhcp` mid-work, restart it, and record exactly what state survived, what
was lost, and what it re-did. Proof requires before/after state hashes plus a restart log.

## Evidence

`services/dhcp/dhcp.goose` is a state machine over a `Client` value passed by the caller; `dhcp_step(client, now_ms, reply_type, offer)` has no file, block or save/load call. There is no process entry.

## State ledger

| Question | Answer |
|---|---|
| Survived | Nothing. The client state is a value owned by the caller. |
| Lost | State (IDLE/SELECTING/BOUND/…), lease, server id, T1/T2 and retry counters. |
| Re-did | A new client starts at IDLE and must DISCOVER again; the lease it held is gone even if the server still considers it bound. |

## Gap

There is no DHCP process to kill and no persisted client. A restart test would have to invent the process and the store.

## Owner

dhcp client lifecycle; supervisor spawn contract.
