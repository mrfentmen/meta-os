# R13-051 — dashboard restart / state survival

Status: **GAP FILED — no process or state file**.

## Requested condition

Kill `services/dashboard` mid-work, restart it, and record exactly what state survived, what
was lost, and what it re-did. Proof requires before/after state hashes plus a restart log.

## Evidence

`grep -nEi 'state file|save|load|persist|restart' services/dashboard/*.goose` returns no persistence path. `dashboard.goose:135-142` reads `samples[kind]`, a static in-memory array. `df_init` resets the table.

## State ledger

| Question | Answer |
|---|---|
| Survived | Nothing. The four samples are process memory. |
| Lost | Every sample, its timestamp and the per-kind window overrides. |
| Re-did | A restarted process starts with `have == false` for every kind; `df_get` reports `DF_NEVER` until a producer samples again. |

## Gap

A kill-mid-work test needs a dashboard process and a save/load path; neither exists. The in-memory loss is certain from the source, but there is no before/after hash to produce without inventing a process.

## Owner

dashboard persistence; supervisor spawn contract.
