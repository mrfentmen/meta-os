# R13-057 — dock restart / state survival

Status: **GAP FILED — in-memory list only**.

## Requested condition

Kill `services/dock` mid-work, restart it, and record exactly what state survived, what
was lost, and what it re-did. Proof requires before/after state hashes plus a restart log.

## Evidence

`services/dock/dock.goose` keeps `items` in a static array with pinned/running/pending state and counters. There is no save/load, file or state-file path.

## State ledger

| Question | Answer |
|---|---|
| Survived | Nothing. The pinned list and launch handshake are process memory. |
| Lost | Pinned order, running/pending flags, pending timestamps, per-app launch/failure counters. |
| Re-did | A restarted dock starts empty; every pin must be re-added, and a launch pending at the kill is neither resolved nor counted as an expiry. |

## Gap

No dock process and no state file. The restart drill needs both.

## Owner

dock persistence; supervisor spawn contract.
