The apps you need

MetaOS 1.0 installs the full desktop application set — what you see in the live session is what lands on your disk.

  • Files: the Thunar file manager for browsing, copying, and organizing your documents.
  • Terminal: a fast terminal for the command line, one click from the menu.
  • Settings: the Settings Manager for display, keyboard, appearance, and devices.
  • Browser and extras: the Firefox web browser, the Mousepad text editor, and the Ristretto image viewer.
