Your desktop

The first thing you will see after install is a familiar, uncluttered desktop — the same one running in this live session.

  • Top panel: status icons and the clock live here, always one glance away.
  • Application menu: the menu button in the top-left opens every installed program, with search as you type.
  • Trash and Home sit on the desktop itself, over the Meta rays wallpaper.
  • Dock: the Plank dock ships installed with the system for one-click launches. How it presents in daily use is still to be proven in a live session — not yet verified.
