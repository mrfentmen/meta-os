Under the surface

An OS for agents, too

MetaOS is designed as an operating system for agents: named workers with a lane, a budget, and a receipt for everything they do.

  • Always sweeping: a patrol loop watches for work, and an investigation loop starts when something needs a closer look.
  • Woken, never guessing: a small watchman wakes the right agent with its orders, budget, and deadline already assembled.
  • Honest boundary: the agent programs run on the host machine in the MetaOS project today. This installer lays down the desktop system only — it does not install or start agents. Agent autostart on installed systems is roadmap, not shipped.
