# Greeter key validation — lightdm-gtk-greeter

Target: `lightdm-gtk-greeter` (ships in the base image per ISO manifest).
GDM is **not** a target: no GDM theme/keys ship in this lane.

## Sources

- Upstream canonical template:
  `Xubuntu/lightdm-gtk-greeter` master,
  `data/lightdm-gtk-greeter.conf` (commented key list — authoritative).
- Upstream `NEWS`: `show-indicators` deprecated in favour of `indicators`
  (new name lists indicator modules incl. `~host`, `~spacer`, `~clock`,
  `~session`, `~power`).
- Context7 library lookup for `lightdm-gtk-greeter`: no entry (not a code
  library) — validated directly against the upstream template above.

`user-background`, `laptop`, `transition-duration`.

## Deliberately NOT present

- `background-color` — **not an upstream key** (removed from our conf;
  flat-color fallback is `background=#070B16`, same key).
- `logo` — **not a gtk-greeter key** (that spelling belongs to
  `slick-greeter`, which is not the target). Logo wiring here is
  `background=` (wallpaper carrying the brand) + `default-user-image=`
  (M mark avatar) + `icon-theme-name=` (recolored set).
- `show-clock` — historical key; current template drives the clock via the
  `~clock` indicator entry (present in our `indicators`).

## Logo wiring summary

1. backdrop: `/usr/share/backgrounds/meta-rays.png` (`background=`)
2. mark: `/usr/share/backgrounds/meta-m.png` (`default-user-image=`),
   generated by `splash/generate-splash.py`, installed by `apply.sh`
3. icons: `MetaOS` Papirus recolor (`icon-theme-name=`, `icons/ICONS.md`)

## Unity companion (this lane, D)

`unity-greeter.conf` targets the greeter actually installed in the image
(`unity-greeter`, per `dpkg-query` on `/tmp/metaos.ext4`): `background=` (the
blue `meta-rays.png` field), `logo=` (the M `meta-m.png` mark), plus the same
`font-name=Inter 11` / `theme-name=MetaOS` / `icon-theme-name=metaos` the
gtk-greeter conf carries. Unknown keys are ignored by the greeter, so the
font/theme/icon lines are best-effort; background + logo are the wired pair.
Autologin is NOT configured here — it lives in `lightdm.conf.d/` (link 1).
