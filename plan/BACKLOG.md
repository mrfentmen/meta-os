# Meta OS — backlog (the big achievements)

This is the hand-written half of the plan. `plan/QUEUE.jsonl` (generated by
`node plan/gen_queue.mjs`) is the file-scoped half: 401 items that each name a
real file and a check that can fail. Together they are 543 items; 164 of the
generated ones are de-Ubuntu passes over named files.

Every line here is a deliverable with an acceptance test a stranger can run.
Sizes: **S** under a day, **M** one to three days, **L** one to two weeks.

Rule for anyone picking these up: no mock in a path that claims to work. If a
piece is not done, it says so on screen and in the report, and the plan keeps a
line for it.

---

## B1. Native desktop — stop shipping web pages as apps

Today the dock launches a mix of real GTK programs and a browser dressed as an
app. This epic is the difference between "desktop" and "OS".

- [ ] **B1.1 Window manager: one identity, Meta buttons** (M) — own the titlebar, the traffic lights and the shadow. *Done:* every window on a fresh boot draws Meta chrome; no theme falls back to Adwaita grey.
- [ ] **B1.2 Launcher: a real Meta menu, not Whisker** (L) — search, recent, sections, and the mark. *Done:* Super opens it in under 120 ms; it lists only installed apps; keyboard-only path works.
- [ ] **B1.3 Dock: own process, not plank** (L) — zoom, badges, running dots, drag reorder, progress on tiles. *Done:* dock survives plank being removed; all 19 tiles launch; settings persist across reboot.
- [ ] **B1.4 Notification centre** (M) — one bus, history, per-app mute, do-not-disturb. *Done:* `notify-send` lands in it; agent notices appear; DND holds for the window set.
- [ ] **B1.5 Control centre** (M) — wifi, volume, brightness, battery, agents-on/off in one panel. *Done:* every toggle is wired to a real backend or says "not on this machine".
- [ ] **B1.6 System settings app** (L) — replace xfce4-settings with a Meta app over one config store. *Done:* display, sound, network, appearance, privacy, agents all live there; nothing opens the XFCE dialog.
- [ ] **B1.7 Global search across apps, files, agents and runs** (L) — *Done:* one query returns all four kinds, with a source label; empty state is useful.
- [ ] **B1.8 Workspaces with a spatial map** (M) — *Done:* four spaces, animated, keyboard switch, window memory per space.
- [ ] **B1.9 Lock screen and session menu** (M) — *Done:* lock is real (no bypass), session menu has lock/logout/restart/shutdown that work.
- [ ] **B1.10 Multi-monitor** (M) — *Done:* top bar and dock on the right display, per-display scaling, no window stuck off-screen.
- [ ] **B1.11 Clipboard history + screenshot tool** (M) — *Done:* Super+Shift+4 region capture saved to `~/Pictures/Meta`, paste history with pin.
- [ ] **B1.12 File manager: Thunar out, Meta Files in** (L) — *Done:* browse, rename, trash, mount, search; opens from dock; no `thunar` process anywhere on boot.
- [ ] **B1.13 Terminal: brand and profile** (S) — *Done:* prompt, palette, splash line; `meta-code` and `meta-ask` discoverable.
- [ ] **B1.14 Text editor with Markdown preview** (M) — *Done:* opens `.md` with rendered preview, saves without data loss on crash.
- [ ] **B1.15 Media player for Musica output** (M) — *Done:* plays a generated track, shows metadata, no browser.
- [ ] **B1.16 First-run experience** (M) — name, wallpaper, key setup, agent consent. *Done:* new user lands on a working desktop with identity set; skip leaves a visible reminder.
- [ ] **B1.17 Remove the kiosk path from the shipped build** (S) — *Done:* `/etc/metaos/kiosk` no longer exists; docs say desktop only.
- [ ] **B1.18 Accessibility baseline** (M) — *Done:* screen reader starts, font scaling 200% does not clip, high-contrast theme complete.

## B2. The agentic core — make "agentic OS" true

The loop exists and is measured (8/8 in `evals/agentic`). This epic makes it the
way the OS works, not a feature beside it.

- [ ] **B2.1 Scheduler with real priorities** (L) — one queue, priorities, deadlines, preemption of low-priority runs. *Done:* a deadline job beats a background sweep and the ledger shows the order.
- [ ] **B2.2 Persistent agent memory** (L) — per-agent notes, retrieval, expiry, cap. *Done:* an agent reuses a fact from yesterday in a graded task; memory over cap refuses loudly.
- [ ] **B2.3 Tool registry v2** (M) — declared tools with schemas and costs, not hardcoded switches. *Done:* adding a tool is one file; unknown tool refused; self-test covers each.
- [ ] **B2.4 Sandbox the `run` tool** (L) — namespace or container per run with a mount allow-list. *Done:* a run cannot read `/etc/shadow` even with a shell; the refusal is a result, not a crash.
- [ ] **B2.5 Human approval gate** (M) — risky actions pause and ask, with a timeout that defaults to "no". *Done:* a destructive command blocks on a dialog; expiry writes a refusal.
- [ ] **B2.6 Multi-agent handoff** (L) — one run can hand a subtask to another agent and collect the result. *Done:* a two-agent task completes with both transcripts linked.
- [ ] **B2.7 Agent-authored UI** (L) — an agent can request a small form instead of guessing. *Done:* a checkbox list is generated, answered, and recorded in the run.
- [ ] **B2.8 Cost governor across the machine** (M) — daily cap, per-agent cap, visible spend. *Done:* cap hit pauses the queue with a banner; no silent spend.
- [ ] **B2.9 Offline mode** (M) — no key/network => agents queue work and say so. *Done:* pull the network, submit a job, it waits with a named reason and resumes.
- [ ] **B2.10 Run replay** (M) — re-run a recorded transcript against a new model. *Done:* two results diff side by side.
- [ ] **B2.11 Eval suite at 25 tasks, scored on the booted OS** (L) — *Done:* `evals/agentic` runs in the guest, report lands in `~/Meta/eval`.
- [ ] **B2.12 Refusal suite** (M) — destructive, secret-seeking, out-of-workspace. *Done:* each refusal graded; a leak fails the suite.
- [ ] **B2.13 Agent-to-agent messaging** (M) — a mailbox with delivery receipts. *Done:* two agents exchange one message in a run.
- [ ] **B2.14 Skill packs** (L) — installable capability bundles with a manifest and tests. *Done:* install one, it appears to agents; uninstall removes tools.
- [ ] **B2.15 Deterministic replay of a failed run** (M) — same inputs, same tool results, no model call. *Done:* debugging a failure needs no tokens.
- [ ] **B2.16 Local fallback model** (L) — small model for routing/classification when offline. *Done:* routing works with the network down; quality limits documented.
- [ ] **B2.17 Agent health surface** (S) — heartbeat, last error, queue depth on the bar. *Done:* killing an agent turns the dot red within 10 s.
- [ ] **B2.18 Kill switch** (S) — one action stops all agents and says how to resume. *Done:* tested on a live run; resume works.

## B12. De-Linux (the mechanical half)

164 generated items in `QUEUE.jsonl` (`DB-*`), one per file that still names
Ubuntu, Xubuntu or Canonical. The acceptance rule for all of them:

- no user-visible Ubuntu string remains;
- technical identifiers apt/kernel need (`ID_LIKE=debian`, `noble` sources,
  package names) are kept **and marked as compatibility**;
- any behavioural change is named in the commit;
- `sh os-build/identity/debrand.sh <root> --check` stays PASS.

Already done and verified: `/etc/os-release`, `/usr/lib/os-release`,
`/etc/lsb-release` (`MetaOS` / `ribbon`), `/etc/issue`, `/etc/issue.net`,
`10-help-text` and `50-motd-news` disabled. `lsb_release -a` on the image reads
`Meta OS 1.0 (Ribbon)`, codename `ribbon`.
